# Feldcheck Wangerooge West

Web-App zur Feldprüfung der OL-Karte Wangerooge West: Karte mit GPS-Position, Prüfpunkte bestätigen/korrigieren, neue Landmarken und Schleichpfade erfassen, offline nutzbar.

Läuft als statische Seite (GitHub Pages: Branch `main`, Ordner `/`).

Daten: © OpenStreetMap-Mitwirkende (ODbL) · LGLN DGM1 & DOP20, CC BY 4.0.
