# Feldcheck Wangerooge West

Orientierungslauf-Karte für den Westen von Wangerooge (Start: Inselheim Rüstringen mit Sternwarte).

- **Web-App** (diese Wurzel, über GitHub Pages): Karte mit GPS-Position, Prüfpunkte vor Ort bestätigen oder korrigieren, neue Landmarken und Schleichpfade erfassen, offline nutzbar. Ergebnis über „Mehr → Briefkasten“ direkt einsenden (oder „Ergebnis teilen“ als Datei). Unter „Mehr → Karte als PDF“ Blätter und Ebenen wählen und das PDF aufs Handy laden.
- **Briefkasten**: Einsendungen landen im Zweig `eingang`, werden automatisch eingearbeitet und als Pull Request zur Freigabe vorgelegt (siehe [`karte/README.md`](karte/README.md#feldcheck-briefkasten-einsendungen-aus-der-app)).
- **Kartenkette** (`karte/`): Rohdaten, Skripte und Ergebnisse – Karten-PDFs, Landmarkenliste, Web-App. Siehe [`karte/README.md`](karte/README.md).
